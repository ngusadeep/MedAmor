## Purpose
Standardized procedures for emergency response to ensure patient safety and staff protection.

## Emergency Response System

### Code System
- Code Blue: Cardiac arrest
- Code Red: Fire
- Code Yellow: Bomb threat
- Code Black: Infrastructure failure
- Code Silver: Active shooter/hostage
- Code White: Violent person
- Code Green: Evacuation
- Code Orange: Hazardous spill

### Response Teams
- Rapid Response Team (RRT)
- Code Blue Team
- Emergency Response Team
- Disaster Response Team
